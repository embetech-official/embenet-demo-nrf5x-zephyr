Detailed Description

Multiprotocol interface for the EMBENET NODE Port.

Embetech sp. z o.o.
Version
2.0.0
Purpose: embeNET PORT API

Lets the stack share the transceiver with another protocol on the same device, such as Bluetooth LE. The stack requests every timeslot ahead of time, uses the transceiver only in the timeslots the port grants, and releases each one when done.

Only a port that shares the transceiver implements this interface. It calls EMBENET_MULTIPROTOCOL_OnGranted and EMBENET_MULTIPROTOCOL_OnEndGuard, and that reference is what links the stack's multiprotocol support in. A port that does not share the transceiver leaves this interface out entirely: nothing references it, and the stack's multiprotocol code is not linked. 

stack                                                    port
  | EMBENET_MULTIPROTOCOL_Request(now, start, duration)    |   one timeslot ahead
  | -----------------------------------------------------> |
  |                     EMBENET_MULTIPROTOCOL_OnGranted()  |   at start
  | <----------------------------------------------------- |
  | EMBENET_RADIO_Init(), frame exchange,                  |
  | EMBENET_RADIO_Idle(), EMBENET_RADIO_Deinit()           |
  | EMBENET_MULTIPROTOCOL_Release()                        |
  | -----------------------------------------------------> |

  |                    EMBENET_MULTIPROTOCOL_OnEndGuard()  |   at start + duration - end_guard_us, if not released
  | <----------------------------------------------------- |
  | EMBENET_RADIO_Idle(), EMBENET_RADIO_Deinit()           |   the activity is abandoned

All times are in microseconds, in the time base of EMBENET_TIMER_ReadCounter.

Note
While the transceiver is shared, it is initialized and deinitialized in every granted timeslot.
