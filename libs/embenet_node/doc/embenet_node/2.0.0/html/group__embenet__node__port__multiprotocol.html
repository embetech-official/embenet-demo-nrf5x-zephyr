◆ EMBENET_MULTIPROTOCOL_Init()

bool EMBENET_MULTIPROTOCOL_Init ( void * context,
uint32_t end_guard_us )

Starts sharing the transceiver.

Called by EMBENET_NODE_Init, instead of EMBENET_RADIO_Init, when the port's multiprotocol support is linked in. A port that can share the transceiver but is not to do so now, for example by its configuration, returns false; the stack then owns the transceiver from EMBENET_NODE_Init to EMBENET_NODE_Deinit and calls no other function of this interface.

Once it returns true, the port calls EMBENET_MULTIPROTOCOL_OnGranted with context at the start of a requested timeslot, as close to the requested start as it can; up to ~100 us late is tolerated. It calls EMBENET_MULTIPROTOCOL_OnEndGuard with context end_guard_us before the end of a granted timeslot the stack has not released; the stack abandons its activity and deinitializes the transceiver before returning, and the timeslot is then released.

Parameters
[in]contextpassed to both callbacks
[in]end_guard_ushow long before the end of a granted timeslot EMBENET_MULTIPROTOCOL_OnEndGuard is called
Returns
true if the transceiver is shared from now on

◆ EMBENET_MULTIPROTOCOL_Deinit()

void EMBENET_MULTIPROTOCOL_Deinit ( void )

Stops sharing the transceiver.

Called by EMBENET_NODE_Deinit, only if EMBENET_MULTIPROTOCOL_Init returned true. No callback may be called after it returns.

◆ EMBENET_MULTIPROTOCOL_Request()

void EMBENET_MULTIPROTOCOL_Request ( uint32_t now_us,
uint32_t start_us,
uint32_t duration_us )

Requests a timeslot.

The stack requests a timeslot about one timeslot ahead. A new request replaces an earlier one that the port can still withdraw; one already started or committed to stands. The port may decline any request, for example when the other protocol needs the transceiver; the stack then skips that timeslot.

Parameters
[in]now_uscurrent time, read by the stack when making the request
[in]start_uswhen the timeslot starts; now_us + (start_us - now_us) with wrap-around
[in]duration_ushow long the timeslot lasts
Note
May be called from interrupt context; must not block.

◆ EMBENET_MULTIPROTOCOL_Release()

void EMBENET_MULTIPROTOCOL_Release ( void )

Releases the granted timeslot.

Called with the transceiver already deinitialized, normally well before the end guard, and from within the grant callback for a timeslot the stack refuses. Does nothing when no timeslot is granted.

Note
May be called from interrupt context, including the stack's callbacks; must not block.
