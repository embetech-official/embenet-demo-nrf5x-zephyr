Radio Interface

Detailed Description

Provides interface to the radio transceiver. 

                                                       UNINITIALIZED (after hardware reset)
                                                           |
                                                           | EMBENET_RADIO_Init
                                                           |
                                                          \|/
             (from any state except UNINITIALIZED) EMBENET_RADIO_Idle ------> IDLE
                                                           |
                                                           |
                                      EMBENET_TxEnable     |     EMBENET_RxEnable
               -------> TX_READY <--------------------------------------------------------> RX_READY <---------------------------------------------------
             |             |                                                                   |                                                        |
             |             |  EMBENET_RADIO_TxNow                                              | EMBENET_RADIO_RxNow                                    |
             |             | (calls onFrameStart on start of TX frame)                 |                                                        |

EMBENET_TxEnable | |/ |/ | | TX LISTEN | | | | | | | (calls onFrameEnd on end of frame) | (calls onFrameStart on start of RX frame) | | | | | | |/ (calls onFrameEnd on end of RX frame) |/ | --------—ACTIVE <----------------------------------------------------------— RX | | |

| EMBENET_RxEnable |

Only primitive types are used, so a port may implement these functions without including this header. Times are in microseconds, in the time base of EMBENET_TIMER_ReadCounter; powers are in dBm.

Function arguments are valid by contract (channels are in [0, EMBENET_RADIO_GetChannelCount), checked against the stack configuration in EMBENET_NODE_Init, power is within [EMBENET_RADIO_GetMinTxPowerDbm, EMBENET_RADIO_GetMaxTxPowerDbm], frame length within [1, EMBENET_RADIO_MAX_PSDU_LENGTH]). Hardware failures are not reported: the MAC watchdogs recover from a radio that does not do what it was told. The port must always leave the radio in a state from which EMBENET_RADIO_Idle recovers.

◆ EMBENET_RADIO_Init()

bool EMBENET_RADIO_Init ( void )

Initializes the radio transceiver and places it in the IDLE state.

Note
Called once during EMBENET_NODE_Init - or, while the transceiver is shared (see embenet_port/multiprotocol.h), from the grant callback of every timeslot, paired with EMBENET_RADIO_Deinit at its end.
Return values
trueon success
falsethe radio hardware does not respond; EMBENET_NODE_Init fails, or the shared timeslot is abandoned

◆ EMBENET_RADIO_GetChannelCount()

uint32_t EMBENET_RADIO_GetChannelCount ( void )

Returns the number of radio channels; valid channel numbers are [0, count).

Channel number to frequency mapping is the port's channel plan and must match the band of the configuration passed to EMBENET_NODE_Init (863-870 MHz: channel n = 863.1 MHz + n * 100 kHz, 69 channels; 2400-2480 MHz BLE PHY: 40 channels). EMBENET_NODE_Init fails when the configuration uses a channel outside this range.
