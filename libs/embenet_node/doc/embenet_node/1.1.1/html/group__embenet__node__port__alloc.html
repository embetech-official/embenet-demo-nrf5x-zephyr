Memory Allocator Interface

Detailed Description

Interface for stack buffer allocation.

Implementations are not required to use dynamic memory; a static buffer is a valid and common approach.

Function Documentation

◆ EMBENET_ALLOCATOR_Alloc()

void * EMBENET_ALLOCATOR_Alloc ( size_t size)

Allocates the stack's internal memory buffer.

Called exactly once during EMBENET_NODE_Init. The returned pointer must remain valid until EMBENET_ALLOCATOR_Free is called.

Parameters
[in]sizenumber of bytes to allocate
Returns
Pointer to a memory block of at least size bytes with alignment of alignof(max_align_t); must not be NULL.

◆ EMBENET_ALLOCATOR_Free()

void EMBENET_ALLOCATOR_Free ( void * pool)

Releases the stack's internal memory buffer.

Called exactly once during EMBENET_NODE_Deinit with the pointer previously returned by EMBENET_ALLOCATOR_Alloc.

Parameters
[in]poolpointer returned by EMBENET_ALLOCATOR_Alloc; must not be NULL.
