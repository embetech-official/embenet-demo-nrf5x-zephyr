Border Router Communication Interface

Detailed Description

This interface is used only by root instances of the embeNET Node.

It provides the means to communicate with the embeNET Border Router, typically over a UART or other serial connection.

◆ EMBENET_BRT_Receive()

size_t EMBENET_BRT_Receive ( void * packetBuffer,
size_t packetBufferSize )

Receives a framed data packet from the border router (non-blocking).

If a complete packet is available and fits in packetBuffer, it is copied into the buffer and its size is returned. If the available packet is larger than packetBufferSize, no data is copied and 0 is returned. If no packet is available, 0 is returned.

Parameters
[out]packetBufferbuffer to store the received packet; must not be NULL.
[in]packetBufferSizesize of packetBuffer in bytes.
Returns
Number of bytes written into packetBuffer, or 0 if no packet was available or the buffer was too small.
