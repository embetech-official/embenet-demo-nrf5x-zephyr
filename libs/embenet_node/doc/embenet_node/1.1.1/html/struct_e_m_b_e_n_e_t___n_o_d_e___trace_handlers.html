EMBENET_NODE_TraceHandlers Struct Reference
Trace functions

Detailed Description

Set of trace callbacks.

Set any field to NULL to disable that particular trace event. The pointed-to structure must remain valid until EMBENET_NODE_SetTraceHandlers is called again or the stack is deinitialized.
