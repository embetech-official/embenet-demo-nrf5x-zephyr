◆ EMBENET_RADIO_TxEnable()

EMBENET_RADIO_Status EMBENET_RADIO_TxEnable ( EMBENET_RADIO_Channel channel,
EMBENET_RADIO_Power txp,
uint8_t const * psdu,
size_t psduLen )

Wakes the transceiver from IDLE and loads a frame into the TX buffer ready for immediate transmission.

Transitions the radio from IDLE to TX_READY. The frame data pointed to by psdu must remain valid until EMBENET_RADIO_TxNow has been called and the end-of-frame callback has fired.

Parameters
[in]channelradio channel to transmit on
[in]txptransmit power in dBm
[in]psdupointer to the frame payload; must not be NULL
[in]psduLenframe length in bytes; must be in the range [EMBENET_RADIO_MIN_PSDU_LENGTH, EMBENET_RADIO_MAX_PSDU_LENGTH]
Return values
EMBENET_RADIO_STATUS_SUCCESSon success
EMBENET_RADIO_STATUS_PARAMETER_ARGS_OUT_OF_BOUNDSif psduLen is outside the valid range
EMBENET_RADIO_STATUS_COMMUNICATION_ERRORif the radio hardware does not respond

◆ EMBENET_RADIO_GetReceivedFrame()

EMBENET_RADIO_RxInfo EMBENET_RADIO_GetReceivedFrame ( uint8_t * buffer,
size_t bufferLength )

Copies the last received frame into the caller-supplied buffer.

Must be called after the onEndFrame callback fires. Up to bufferLength bytes are written into buffer. The EMBENET_RADIO_RxInfo::mpduLength field in the returned structure reflects the number of bytes actually written (clamped to bufferLength). If the received frame was longer than bufferLength, EMBENET_RADIO_RxInfo::crcValid is set to false.

Parameters
[out]bufferdestination buffer; must not be NULL
[in]bufferLengthsize of buffer in bytes; should be at least EMBENET_RADIO_MAX_PSDU_LENGTH to avoid truncation
Returns
EMBENET_RADIO_RxInfo describing the received frame.
