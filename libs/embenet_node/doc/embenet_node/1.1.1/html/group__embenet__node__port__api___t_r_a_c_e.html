◆ EMBENET_NODE_SetTraceHandlers()

void EMBENET_NODE_SetTraceHandlers ( EMBENET_NODE_TraceHandlers const * traceHandlers)

Installs trace handlers.

Replaces the currently active set of trace handlers. May be called at any time after EMBENET_NODE_Init. The pointed-to structure must remain valid until this function is called again or EMBENET_NODE_Deinit is called.

Parameters
[in]traceHandlerspointer to the trace handler structure; may be NULL to disable all trace callbacks.
