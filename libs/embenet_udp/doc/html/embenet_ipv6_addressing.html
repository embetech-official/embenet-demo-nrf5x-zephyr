embeNET IPv6 addressing

Introduction

Every node in an embeNET network is addressed using an IPv6 address built from two components:

  • a network prefix (EMBENET_NetworkPrefix) — the upper 64 bits, common to every node in the network
  • a UID (EMBENET_EUI64) — the lower 64 bits, the node's own unique identifier

There are two kinds of traffic addressed this way:

  • unicast traffic, sent to one particular destination node identified by its own unicast address
  • multicast traffic, sent to a group of nodes using group addressing (a node may belong to none, one, or several groups, and its group membership may change over time)

Assembling a unicast address

Given a network prefix and a node's UID, EMBENET_AssembleUnicastIpv6 builds the corresponding unicast address:

// Network prefix 2001:0db8:0000:0000, node UID 0000:0000:1234:5678
EMBENET_IPV6 unicastAddr = EMBENET_AssembleUnicastIpv6(0x20010db800000000, 0x0000000012345678);

The reverse operation, extracting a node's UID back out of one of its unicast addresses, is done with EMBENET_GetUidFromIpv6.

Assembling a multicast address

Multicast addresses identify a group (EMBENET_GroupId) within a network, rather than a single node. They follow the RFC 3306 embedded-RP format: FF34:0040:[prefix]:0000:[gid]. EMBENET_AssembleMulticastIpv6 builds such an address from a network prefix and a group ID:

// Multicast address for group 12 in network prefix 2001:0db8:0000:0000
EMBENET_IPV6 multicastAddr12 = EMBENET_AssembleMulticastIpv6(0x20010db800000000, 12);
// Multicast address for group 15 in the same network
EMBENET_IPV6 multicastAddr15 = EMBENET_AssembleMulticastIpv6(0x20010db800000000, 15);
