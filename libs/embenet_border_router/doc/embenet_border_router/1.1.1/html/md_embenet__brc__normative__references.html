Normative References

This document lists the RFCs and drafts that the embeNET Border Router protocol stack is based on, grouped by topic. For each one: what it covers, and where in this codebase it is relevant. Use it to find the right spec before implementing or debugging a given piece of protocol behavior.

Core IPv6

  • RFC 8200 — Internet Protocol, Version 6. Base header format, extension header chain, fragmentation, upper-layer pseudo-header checksums. Relevant to packet parsing, extension header ordering, fragment reassembly, and checksum calculation.
  • RFC 4291 — IPv6 Addressing Architecture. Address types, text representation, modified EUI-64 interface identifiers, multicast scopes. Relevant to address validation/formatting and deriving interface identifiers from MAC addresses.
  • RFC 4443 — ICMPv6. Message format, error types (unreachable, too big, time exceeded, parameter problem), echo request/reply. Relevant to generating error responses and ping/pong handling.
  • RFC 4861 — Neighbor Discovery for IPv6. RS/RA/NS/NA/Redirect message formats, neighbor cache state machine (NUD). Relevant to L3-to-L2 address resolution and RA-based gateway selection.
  • RFC 4862 — IPv6 Stateless Address Autoconfiguration. Link-local address formation, Duplicate Address Detection, RA-driven global address configuration, address lifetimes. Relevant to interface auto-configuration.

RPL Routing

  • RFC 6550 — RPL: IPv6 Routing Protocol for Low-Power and Lossy Networks. Core protocol: DODAG, DIO/ DIS/DAO(-ACK) messages, rank, storing vs. non-storing mode, loop avoidance. The foundation for all mesh routing in this project.
  • RFC 6551 — Routing Metrics Used for Path Calculation in LLNs. DAG Metric Container, node state/ energy objects, link ETX/LQL reliability, link color. Relevant to parent selection based on link/node metrics.
  • RFC 6552 — Objective Function Zero (OF0). Rank increase formula and step_of_rank constants, basic parent/successor selection. Relevant to the simplest RPL rank computation, without a full metric container.
  • RFC 6553 — RPL Option for Carrying RPL Information in Data-Plane Datagrams (RPI). Flags, instance ID, sender rank, tunneling rules. Relevant to data-plane loop/error checking and Hop-by-Hop header handling.
  • RFC 6554 — IPv6 Routing Header for Source Routes with RPL (RH3). Compressed address vector, hop-by-hop forwarding and decrement rules. Relevant to non-storing-mode downstream routing.
  • RFC 6719 — Minimum Rank with Hysteresis Objective Function (MRHOF). Additive path cost, hysteresis switch threshold. Relevant to standard RPL parent selection with stability against ETX flapping — this is the objective function actually used in most deployments, as opposed to OF0.
  • RFC 9010 — Routing for RPL-Unaware Leaves (RUL). Bridges 6LoWPAN ND (EARO) registration into RPL DAO host routes, with proxy EDAR/EDAC at the DODAG root. Relevant only if the mesh needs to support non-RPL hosts.

Header Compression & Fragmentation

  • RFC 6282 — Compression Format for IPv6 Datagrams over IEEE 802.15.4 Networks (6LoWPAN IPHC/NHC). IPHC bitmap, address elision via MAC-layer context, UDP port compression. The core of the packet (de)compressor.
  • RFC 8138 — IPv6 over 6LoWPAN Routing Header (6LoRH). Compressed RPI/SRH/IP-in-IP headers for RPL-over-6LoWPAN. Relevant to compressing RPL and source-route headers on the wire.
  • RFC 8724 — SCHC: Static Context Header Compression and Fragmentation. Rule-based header compression with sliding-window fragment ACKs, aimed at LPWAN links (LoRaWAN, Sigfox, NB-IoT). Not currently in scope for this project unless it targets an LPWAN transport.

6LoWPAN Neighbor Discovery & Registration

  • RFC 6775 — Neighbor Discovery Optimization for IPv6 over 6LoWPANs. Address Registration Option (ARO), 6LoWPAN Context Option (6CO), ABRO, DAR/DAC to a 6LBR. Relevant to proactive (non-multicast) ND and stateful compression-context distribution.
  • RFC 8505 — Registration Extensions for 6LoWPAN Neighbor Discovery (EARO). Adds transaction ID sequencing, Registration Ownership Verifier (ROVR), registrar capability signaling. Relevant to mobility tracking and route-injection flags.
  • RFC 8928 — Address-Protected Neighbor Discovery for Low-Power and Lossy Networks (AP-ND). Crypto-ID, Crypto-ID Parameters Option, signature-based challenge-response. Relevant to hardening the network against address theft/spoofing.

TSCH / 6TiSCH

  • RFC 7554 — Using IEEE 802.15.4e TSCH in the IoT: Problem Statement and Goals. Background on timeslots, slotframes, and synchronization methods; informational only.
  • RFC 8180 — Minimal IPv6 over the TSCH Mode of IEEE 802.15.4e (6TiSCH) Configuration. Minimal shared cell, Enhanced Beacon format, join metric, RPL-over-TSCH parameters. Relevant to the bootstrap/join phase and EB parsing.
  • RFC 9033 — 6TiSCH Minimal Scheduling Function (MSF). SAX-hash autonomous cells, six-step pledge join sequence, dynamic cell add/delete via 6P, schedule collision handling. Published as a Proposed Standard in May 2021 — supersedes the earlier draft-chang-6tisch-msf drafts, so use this RFC, not the drafts, for section references.
  • RFC 8480 — 6top Protocol (6P). Transaction format, CellOptions, ADD/DELETE/RELOCATE/COUNT/LIST/CLEAR commands. Relevant to L2 cell negotiation between neighbors.

Security & Enrollment

  • RFC 7030 — Enrollment over Secure Transport (EST). Certificate enrollment/re-enrollment over HTTPS (/cacerts, /simpleenroll, etc.), CSR attributes. Relevant to PKI credential bootstrap and rollover.
  • RFC 8613 — Object Security for Constrained RESTful Environments (OSCORE). CoAP object security context, option classes (E/I/U), COSE Encrypt0 mapping, replay window. Relevant to end-to-end CoAP encryption/integrity and replay protection.
  • RFC 8933 — CMS Updates for Algorithm Identifier Protection. Binds the signed-attributes digest algorithm to the content digest algorithm. Relevant to hardening CMS signed/authenticated envelopes against algorithm substitution.
  • RFC 9528 — Ephemeral Diffie-Hellman Over COSE (EDHOC). Lightweight authenticated key exchange, message_1 through message_4, transcript-hash-based key derivation. Relevant to deriving OSCORE keys with minimal overhead.

Out of scope, listed for completeness

  • RFC 8934 — PCEP Extensions for LSP Scheduling with Stateful PCE. Traffic-engineering / scheduled-LSP extensions to PCEP; unrelated to the border router's routing or transport stack.
