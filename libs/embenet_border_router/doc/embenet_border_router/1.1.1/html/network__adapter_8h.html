bool EMBENET_BR_PORT_NetworkAdapterGetAddress ( EMBENET_BR_PORT_NetworkAdapter const * adapter,
uint8_t * address_buffer )

Returns the current unicast address of the network adapter instance.

If the network adapter uses multiple addresses, the function SHALL return the first one. If the network adapter does not have an address or is in DOWN state, the function SHALL return zeroed-out value.

Parameters
[in]adapterNetwork adapter instance.
[in]address_bufferBuffer to store the address. Must be at least 16 bytes long.
Return values
trueif the interface has any unicast IPv6 Address.
falseif the interface has no unicast IPv6 Address.
Postcondition
address_buffer is filled with the current unicast IPv6 address of the network adapter, or zeroed-out value if no address is assigned.

◆ EMBENET_BR_PORT_NetworkAdapterWrite()

bool EMBENET_BR_PORT_NetworkAdapterWrite ( EMBENET_BR_PORT_NetworkAdapter * adapter,
void const * data,
size_t data_length )

Writes the data to the network adapter.

It is assumed that the data represent a single IPv6 Packet. The function SHALL return false if the network adapter is DOWN or if the data cannot be sent for any reason. The function MUST preserve the order of the packets.

Whether this function sends the data immediately or queues it for later sending is port-defined. If the function queues the data, the internal queue MUST be flushed when the network adapter is brought UP or DOWN.

Parameters
[in]adapterNetwork adapter instance.
[in]dataPointer to the data to be sent.
[in]data_lengthLength of the data to be sent.
Returns
true if the data was sent successfully, false otherwise.
