◆ up()

std::error_code embenet::border_router::BorderRouter::up ( )
nodiscard

Starts the Border Router operation.

This call is non-blocking: it returns as soon as the WAN/root node interfaces have been opened and the connection attempt to the Root Node has been initiated, without waiting for the Root Node to actually confirm the network start. Outcome of that attempt (success or failure) is reported asynchronously via events (events::NetworkStarted / events::RootNodeConnectionFailed), so it can be observed the same way on every platform this library targets - including bare-metal ports with no OS-level blocking primitive to wait on.

Returns
Status of the operation
Return values
std::errc::operation_not_permittedif configuration is not set
std::errc::no_such_deviceif WAN or root node cannot be brought up
no_erroron success

◆ configure_promiscuous_mode()

void embenet::border_router::BorderRouter::configure_promiscuous_mode ( bool enable = true)

Enable or disable promiscuous mode on the Border Router.

Enabling promiscuous mode will have the following effects:

  • Checksum verification is skipped for incoming packets, both from the root node and from WAN
  • Outgoing multicast packets will NOT be filtered based on the registered multicast groups
  • Traffic consumed locally (addressed to the Border Router's own address, or to a multicast group with a matching local socket) is additionally mirrored onward to WAN
