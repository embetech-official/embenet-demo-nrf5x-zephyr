◆ EMBENET_BR_Init()

EMBENET_BR_Result EMBENET_BR_Init ( EMBENET_BR_Capabilities capabilities)

Initializes the Border Router.

This function must be called before any other Border Router function. The Border Router is initialized in internal, static storage. This API is limited to one Border Router instance. If you need multiple instances, use the C++ API.

Parameters
[in]capabilitiesrequested capabilities of this instance. If unsure, pass the result of EMBENET_BR_GetDefaultCapabilities. When customizing, make sure that the requested capabilities do not exceed the maximum capabilities of the library - see EMBENET_BR_GetMaxCapabilities.
Returns
EMBENET_BR_Result
Note
calling this function will also enable calling of the EMBENET UDP API functions.

◆ EMBENET_BR_Up()

EMBENET_BR_Result EMBENET_BR_Up ( void )

Starts the Border Router operation.

This call is non-blocking: it returns as soon as the WAN/root node interfaces have been opened and the connection attempt to the Root Node has been initiated, without waiting for the Root Node to actually confirm the network start. Outcome of that attempt (success or failure) is reported asynchronously via events (on_network_started / on_root_node_connection_failed in EMBENET_BR_EventHandlers), so it can be observed the same way on every platform this library targets - including bare-metal ports with no OS-level blocking primitive to wait on.

Returns
EMBENET_BR_Result

◆ EMBENET_BR_Down()

EMBENET_BR_Result EMBENET_BR_Down ( void )

Stops the network operation.

User will no longer be able to send and/or receive packets from the network. The list of connected nodes and registered multicast groups will be cleared. List of join rules will not be cleared.

◆ EMBENET_BR_GetNodes()

EMBENET_BR_NodesList EMBENET_BR_GetNodes ( EMBENET_EUI64 * nodes_buffer,
size_t nodes_buffer_size,
size_t offset,
size_t count )

Get the list of the nodes EUI64 in the network.

Parameters
[out]nodes_bufferPointer to memory location where the UIDs will be written. If NULL, no copying will occur, and EMBENET_BR_NodesList::count will be zero.
[in]nodes_buffer_sizeNumber of elements that can be stored in nodes_buffer.
[in]offsetIndex of the first node to retrieve.
[in]countMaximum number of nodes to retrieve. If SIZE_MAX - fills as much as possible.
Returns
EMBENET_BR_NodesList:
  • EMBENET_BR_NodesList::total_count will contain the total number of nodes in the network.
  • EMBENET_BR_NodesList::count will contain the number of UIDs written to the buffer.
  • EMBENET_BR_NodesList::nodes will point to the first node entry written to the buffer. If the buffer is too small to hold all entries, only as many as fit will be written, and total_count > count.
Note
The nodes list may change between subsequent calls to this function.

◆ EMBENET_BR_ConfigurePromiscuousMode()

EMBENET_BR_Result EMBENET_BR_ConfigurePromiscuousMode ( bool enable)

Configures the promiscuous mode of the Border Router.

Enabling it has the following effects:

  • Checksum verification is skipped for incoming packets, both from the root node and from WAN
  • Outgoing multicast packets are not filtered based on the registered multicast groups
  • Traffic consumed locally (addressed to the Border Router's own address, or to a multicast group with a matching local socket) is additionally mirrored onward to WAN
Parameters
[in]enabletrue to enable promiscuous mode, false to disable it.
Returns
EMBENET_BR_Result
