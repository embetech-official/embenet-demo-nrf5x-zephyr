◆ EMBENET_BR_PORT_MutexCreate()

EMBENET_BR_PORT_Mutex * EMBENET_BR_PORT_MutexCreate ( void )

Returns a new mutex instance.

Returns
new mutex instance, or NULL if the mutex cannot be created.
Postcondition
The returned instance is valid until it is destroyed by EMBENET_BR_PORT_MutexDestroy().
The mutex instance is in an UNLOCKED state.
Warning
The implementation of this function MUST be thread-safe.

void EMBENET_BR_PORT_MutexLock ( EMBENET_BR_PORT_Mutex * mutex)

Locks the mutex.

If another thread has already locked the mutex, the function MUST block execution until the lock is acquired.

Parameters
[in]mutexInstance to be locked.
Precondition
mutex was obtained from EMBENET_BR_PORT_MutexCreate().
Postcondition
The mutex instance is in a LOCKED state.
Warning
The implementation of this function MUST be thread-safe.

◆ EMBENET_BR_PORT_MutexTryLock()

bool EMBENET_BR_PORT_MutexTryLock ( EMBENET_BR_PORT_Mutex * mutex)

Tries to lock the mutex.

Returns immediately. On successful lock acquisition returns true, otherwise returns false. This function is allowed to fail spuriously and return false even if the mutex is not currently locked by any other thread.

Parameters
[in]mutexInstance to be locked.
Precondition
mutex was obtained from EMBENET_BR_PORT_MutexCreate().
Returns
true if the lock was acquired successfully, otherwise false.
Postcondition
The mutex instance is in a LOCKED state if the function returns true.
Warning
The implementation of this function MUST be thread-safe.
