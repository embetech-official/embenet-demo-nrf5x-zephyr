void * EMBENET_BR_PORT_Allocate ( size_t size)

Allocates size bytes of uninitialized storage.

If allocation succeeds, the function SHALL return a pointer to the lowest (first) byte in the allocated memory block that is suitably aligned for any scalar type (at least as strictly as max_align_t). If the allocation fails, the function SHALL return a null pointer.

Parameters
[in]sizeNumber of bytes to allocate.
Precondition
size != 0.
Returns
Pointer to the beginning of newly allocated memory, or NULL on failure.
Postcondition
The memory block is valid until it is deallocated by EMBENET_BR_PORT_Deallocate().
The memory block is aligned to the largest alignment requirement of any scalar type.
Warning
The implementation of this function MUST be thread-safe.
