◆ set_border_router_udp_instance()

void embenet::border_router::set_border_router_udp_instance ( BorderRouter * instance)

Assigns the BorderRouter instance to be used by the UDP API functions (EMBENET_UDP_Send and friends), which have no instance parameter of their own.

Called automatically by EMBENET_BR_Init / EMBENET_BR_Deinit for instances created through the C API. Applications that create their own instance directly through the C++ API must call this themselves to make it reachable from the UDP API.

Parameters
[in]instancepointer to the BorderRouter instance, or nullptr to disable UDP API functions

◆ get_border_router_udp_instance()

BorderRouter * embenet::border_router::get_border_router_udp_instance ( )
nodiscard

Returns the BorderRouter instance currently assigned via embenet::border_router::set_border_router_udp_instance(), if any.

Intended for internal wiring between the UDP API implementation and the BorderRouter instance backing it - not meant for general application use.

Returns
pointer to the assigned instance, or nullptr if none is assigned.
