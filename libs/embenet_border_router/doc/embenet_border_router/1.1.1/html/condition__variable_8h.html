◆ EMBENET_BR_PORT_ConditionVariableWaitFor()

bool EMBENET_BR_PORT_ConditionVariableWaitFor ( EMBENET_BR_PORT_ConditionVariable * condition_variable,
EMBENET_BR_PORT_Mutex * mutex,
int64_t timeout_ms )

Atomically unlocks mutex and blocks the calling thread until either another thread calls EMBENET_BR_PORT_ConditionVariableNotifyOne() on condition_variable, or timeout_ms elapses.

In both cases (and also on a spurious wakeup), mutex is re-locked before this function returns - the caller must always re-check its own predicate after this function returns, regardless of the returned value.

A port that cannot actually block is allowed to return immediately (as if woken by a notification, or as if the timeout expired) without violating this contract.

Parameters
[in]condition_variableInstance to wait on.
[in]mutexMutex, currently locked by the calling thread, to unlock while waiting and re-lock before returning.
[in]timeout_msMaximum time to wait, in milliseconds. If zero, the function must not block.
Precondition
condition_variable was obtained from EMBENET_BR_PORT_ConditionVariableCreate().
mutex was obtained from EMBENET_BR_PORT_MutexCreate() and is currently locked by the calling thread.
Returns
true if woken by a notification (or spuriously), false if timeout_ms elapsed first.
Postcondition
mutex is locked by the calling thread again.
Warning
The implementation of this function MUST be thread-safe.
