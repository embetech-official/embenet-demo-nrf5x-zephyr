CRC-16 calculation routines

Detailed Description

#include <embetech/crc16.h>
crc16.h
16-bit CRC calculation routines

This module groups utility functions that calculate 16-bit CRC using various algorithms. Currently CCITT and MODBUS algorithms are supported.
